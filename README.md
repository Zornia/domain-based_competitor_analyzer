# Поиск информации о сайте по домену с помощью WHOIS-сервера

Консольное приложение на Python для получения публичных WHOIS‑данных о домене. Позволяет быстро узнать владельца, регистратора, даты регистрации и истечения, серверы имён и другие сведения.

## Возможности

- Получение WHOIS‑данных через библиотеку `python-whois`.
- Читаемый отчёт в терминале.
- Обработка ошибок и отсутствующих данных.
- Поддержка проверки нескольких доменов в одном сеансе.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `main.py` | Точка входа, CLI‑интерфейс, цикл ввода |
| `api_client.py` | Запрос к WHOIS‑серверу, возврат стандартизированного ответа (`success`, `data`, `error`) |
| `data_processor.py` | Извлечение 9 ключевых полей из сырых данных, защита от отсутствия полей |
| `report.py` | Форматирование и вывод отчёта в консоль (рамка, выравнивание, обработка списков и `None`) |

## Как запустить

1. Установить зависимости:

   ```bash
   pip install python-whois

2. Добавить следующие строки кода в конец файла `main.py`:

    \```
    if __name__ == "__main__":
        main()
    \```

3. Запустить приложение в терминале:

    ```bash
    python main.py
